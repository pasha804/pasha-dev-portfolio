## 🌌 Overview
This repository contains the source code for the **Pasha Dev** portfolio website. Built with React and styled with Tailwind CSS, it features a unique **Cyberpunk/Sci-Fi** aesthetic with glassmorphism, dynamic glowing borders, and a fully integrated AI assistant.

The platform showcases services, high-resolution AI-generated visuals, and provides an interactive quote calculator for clients to estimate project costs.

## ✨ Features
- 🚀 **High-End Cyberpunk UI:** Custom UI components (`CyberCard`, `CyberButton`) with glowing borders, hover telemetry, and smooth micro-animations.
- 🤖 **Pasha AI Consultant:** A built-in AI assistant integrated with the CleanAPIs `claude-opus-5.5` model to interact with clients, answer pricing questions, and qualify leads.
- 💰 **Quote Calculator:** Interactive cost estimator allowing users to build a package and send details straight to WhatsApp.
- 📱 **Mobile Optimized:** A sleek responsive layout with glassmorphic mobile navigation.
- ⚡ **Optimized Performance:** Built with Vite for rapid development and lightning-fast production builds.

## 🛠 Tech Stack
- **Frontend Framework:** React 18
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Custom extended theme with neon colors)
- **Animations:** Framer Motion & custom CSS animations
- **Build Tool:** Vite

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/pasha804/pasha-dev-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd pasha-dev-portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## 🛸 Project Structure
- `/src/components` - Reusable UI components (Navbar, Footer, CyberButtons).
- `/src/sections` - Major page sections (Hero, Pricing, Portfolio).
- `/src/data` - Centralized static data configurations for easy edits.
- `/public` - 8K AI generated visuals, backgrounds, and assets.
